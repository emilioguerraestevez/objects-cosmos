Qué es

  • Un servidor FastAPI (app.py) que sirve el formulario y guarda cada registro en su propia base SQLite, separada de la base maestra.
  • El desplegable de Servicio se llena solo con el catálogo real de la dependencia elegida — 217 servicios en 12 dependencias, el mismo que se depuró esta semana.
  • El servidor rechaza combinaciones inválidas (un servicio que no le pertenece a su dependencia) antes de que lleguen a la base.
  • Folio automático y determinista si el capturista no trae uno propio.

Para correrlo

pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8790
Antes de exponerlo: cambiar CODIGO_ACCESO en app.py (hoy dice cuh2026, es un valor de ejemplo) y servirlo detrás de HTTPS. Cada dependencia puede recibir el mismo link con ?dep=Obras (o la clave que le toque) para que su desplegable de dependencia venga ya fijo.

Incorporación a la base maestra

Los registros del formulario no se mezclan solos con la base maestra. Se incorporan una vez por semana, igual que el SUAC y las listas de las dependencias — mismo ritmo de siempre. incorporar_formulario.py es la referencia de cómo hacerlo, ajustable si la infraestructura oficial usa otro motor de base de datos.
